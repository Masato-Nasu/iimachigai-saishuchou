# 言い間違い採取帳

こどもの言葉と、家族のまなざしを残すための小さな採取帳です。  
AIなし・外部送信なし・端末内保存のPWAです。

## v1.2

- 初回に子どもの名前を入力
- 1人なら「○○語録」
- 兄弟がいる場合は「○○＆○○語録」
- 話した人を兄弟ごとに選択
- 題名・ブラウザタイトル・カードPNGに語録名を反映
- パパのコメント / ママのコメント欄
- カテゴリ入力を削除して、よりシンプルに変更
- 原本写真のファイル選択UIを独自ボタンに変更
- 原本写真・絵・手紙の添付
- 採取帳一覧、話した人別フィルター、年別フィルター、お気に入り
- 原本写真モード
- カードPNG保存
- JSONバックアップ / 復元

## 保存について

データはブラウザ内の IndexedDB と localStorage に保存されます。  
写真も端末内に保存され、追加時に軽く圧縮されます。  
サーバーや外部AIには送信しません。

## デプロイ

展開後に `iimachigai-saishucho` フォルダだけがデスクトップにある場合：

```powershell
cd "$env:USERPROFILE\Desktop\iimachigai-saishucho"
npx wrangler pages deploy . --project-name iimachigai-saishucho
```
